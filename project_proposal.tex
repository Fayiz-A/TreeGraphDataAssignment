\section*{Computational Plan}

Types of computations to perform on the data:

1. Display the graph representation of roads

2. Make a road removable, and use Djiktras algorithm to compute the length of shortest path between point A and
point B that the removed single road had connected previously. Djiktras is used to give the shortest path from one
source node/vertex to all other ones, and it has a time complexity of Theta(V+E(LogV)), so it is best suited to solve
the problem efficiently for the data.

3. Using the same algorithm as above, display the shortest path, and in case of a tie show one of the shortest paths.
